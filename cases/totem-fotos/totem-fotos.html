Sobre o projeto

O projeto consiste no desenvolvimento de totens de fotos interativos, soluções que unem tecnologia e design para proporcionar momentos memoráveis. O objetivo principal é transformar a interação do público com marcas ou temáticas em uma vivência única e envolvente.

Minha atuação cobriu todo o processo de concepção, desde a pesquisa e criação de personas até o design final das interfaces e personalização de marca — atuando como UX/UI Designer, Designer de Produto e Designer Gráfico.

Problema identificado

Muitas ativações de marca em eventos carecem de uma conexão emocional ou de uma forma tangível e compartilhável de recordação, resultando em interações passageiras e baixo engajamento pós-evento.

// SEC_C

Objetivos do projeto

  • Fortalecer a conexão emocional entre o público e a marca/personagem
  • Proporcionar uma interface intuitiva que garanta uma interação rápida e satisfatória
  • Gerar conteúdos compartilháveis que ampliem o alcance da experiência
// SEC_D

Processo de design

Para o desenvolvimento do projeto, foram estabelecidas quatro fases de concepção cuidadosamente percorridas utilizando a técnica do Diamante Duplo:

Descobrir

A fase inicial envolveu investigação dos problemas e geração de ideias, focando em como os totens podem enriquecer a experiência do visitante.

BENCHMARK

Foram analisadas soluções de entretenimento interativo em eventos empresariais e culturais para entender os padrões de interação e expectativa do público e dos clientes. Foram também analisados aplicações do gênero visando entender a tendência do mercado.

MATRIZ CSD

● CERTEZAS

O público quer uma recordação física e imediata do evento

A interface precisa ser extremamente simples para evitar filas

O totem será utilizado por públicos de diferentes idades

● SUPOSIÇÕES

Os utilizadores preferem tirar fotos com "ídolos" específicos

A coleta de e-mail na tela final gera desistência se o teclado for complexo

O compartilhamento via QR Code é mais importante que impressão para jovens

● DÚVIDAS

Os usuários entendem que precisam escanear o QR Code antes de sair?

Como sinalizar fisicamente no móvel onde a foto impressa será retirada?

Definir

A interação deve ser dinâmica e o fluxo deve ser o mais objetivo possível para atender públicos diversos.

FLUXO DE USUÁRIO

Desenvolver

O conceito focou na personalização total. Embora a estrutura funcional seja consistente, a interface deve "respirar" a marca do cliente.

MATRIZ DE PRIORIZAÇÃO

Priorizou-se a facilidade de navegação (Impacto Alto / Esforço Médio) e a personalização visual para cada cliente (Impacto Alto / Esforço Médio).

WIREFRAMES

Criados para definir a arquitetura de informação e garantir que botões de ação (como "Confirmar" ou "Refazer") estivessem sempre claros.

WIREFRAME // FLUXO_USUARIOREC ●

Entregar

As interfaces são personalizadas de forma prática para as marcas ou eventos como Santos FC, Corinthians Basquete, Chiquititas e Hello Kitty.

DECISÕES VISUAIS E DE INTERFACE

  • Tipografia e Cores: adaptadas conforme a marca do cliente para garantir coesão estética. A aplicação tem um sistema de troca de componentes e personalização rápida
  • Tela de Escolha: inclusão de uma tela de "Escolha de Quantidade de Impressões" para dar autonomia ao usuário e aumentar o valor recebido da ativação
  • Totem Físico: apresentação do totem físico personalizado com adesivo laminado e MDF, garantindo a integridade e durabilidade do equipamento
// SEC_E

Design final

Cada elemento visual da aplicação — das estruturas de navegação aos detalhes gráficos — é alinhado com a identidade da marca ou projeto. O processo de design combina princípios de UX/UI com diretrizes visuais da marca para garantir uma experiência coesa, intuitiva e esteticamente alinhada em todos os aspectos.

Feedback

// SEC_G

Aprendizados e reflexões

O maior aprendizado foi equilibrar a consistência do sistema (backend/fluxo) com a flexibilidade visual total (frontend/UI). Entender que em eventos a velocidade de interação é tão importante quanto a estética ajudou a refinar o fluxo para ser o mais enxuto possível.

// SEC_H

Conclusão

O projeto demonstrou que totens interativos são ferramentas poderosas de branding. A solução final entregou uma experiência de usuário fluida que não apenas registra um momento, mas fortalece a identidade da marca no imaginário do público.
